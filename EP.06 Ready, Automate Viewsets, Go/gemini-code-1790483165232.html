STEP 2 // THE INPUTS 3 SIMPLE PARAMETERS ➔

What You Feed the Script

01. COORDINATION VIEW
3D Export View

Select the dedicated 3D view used for clash detection and coordination (e.g., 3D View: NAVISWORKS).

02. FILTER RULE
Sheet Parameter

Filter valid project sheets using a parameter condition (e.g., Drawn By != "AP").

03. TARGET SETS
Viewset Names

Define the submission packages to build (DESIGN, CONSTRUCTION, AS-BUILT).
